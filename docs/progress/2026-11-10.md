# 2026-11-10: from idea to working plugin

## Done

- Product idea: agents write Compose UI but cannot see it. Value is not rendering
  (compose-ai-tools and Android CLI `render-compose-preview` already do that) but the
  loop on top: state matrix, automatic checks, reference comparison, PR evidence.
- Test bed: OrderSummaryCard, ProfileHeader, SettingsRow with 11 planted bugs; answer key
  in `tooling/eval/planted-bugs.md`.
- Spike: Roborazzi + Robolectric render plus a JSON semantics dump per state.
- Checker v0 in Python, then ported to Kotlin (own JSON parser, ImageIO). 9 rules.
- Restructured into a Gradle plugin: adds test deps, generates one parameterized test that
  renders every `@Preview` of a composable (default preview also at font_2x, rtl, dark),
  runs the checker, writes `report.json`.
- Fixes found on the way: AGP 9 ignores legacy `sourceSets.test.java.srcDir` (use variant
  API); `kotlin-dsl` Action lambdas take `this`; material buttons reach 48dp via
  `minimumInteractiveComponentSize` (read outer layout size); previews must wrap `Surface`;
  scroll containers make off-screen items "hidden", not "collapsed"; PowerShell `-P` dots.
- Agent tests: run 3 invalid (hint comments in source); run 4 clean: all planted bugs fixed.
- Packaging: MIT, Claude Code marketplace (`/plugin marketplace add AshwinN796/verify-ui`),
  `com.gradle.plugin-publish` 2.2.1 config. Pushed to GitHub.
- Real app (Bein): multi-flavor support added (auto-pick `<flavor>Debug`, override with
  `-PverifyUiVariant=`). Hit a unit-test manifest merge failure (library minSdk 26 > module 24).
